# Демо SockLock Variants — план зйомки, монтажу й озвучки

**Формат:** до 3:00, 1920×1080, українською. Тон — внутрішній запуск інструмента для дизайнерів:
«ось що в тебе забирало пів дня → ось як тепер → ось як цим користуватись». Не презентація для
інвесторів, а коротке промо + інструкція.

**Хто що робить**
- Скрипти: `demo/record.py` знімає анімовані сцени (`demo/scenes.html`) і справжній прогін застосунку
  на віртуальному екрані (Xvfb + Chrome + ffmpeg); `demo/assemble.py` монтує під озвучку.
- Ти: генеруєш озвучку в ElevenLabs по кліпу на сцену (тексти нижче).

## Озвучка (ElevenLabs)

Один файл на сцену, назва `vo_01.mp3` … `vo_13.mp3` — так я точно підженю відео під голос.
Темп ≈2,3 слова/с; якщо кліп вийде довшим за слот, я розтягну відповідну сцену, а не прискорю голос.
Налаштування: спокійний дружній голос, Stability ~50%, Style низько, без музики (музику додам тихо
під монтажем, якщо захочеш).

**vo_01 (8 с).** Половина твого робочого дня йде не на нові ідеї. Вона йде на переписування одного й
того ж скрипту.

**vo_02 (22 с).** Ось як це виглядає зараз. Беремо скрипт переможця. Вигадуємо новий хук. Перевіряємо,
чи влазить у дві з половиною секунди. Переписуємо першу фразу. Потім текст на екрані. І так двадцять
разів — для кожної модифікації. До обіду таймлайн ще навіть не відкритий.

**vo_03 (18 с).** А компанії треба вдвічі більше. Зараз ми робимо двісті сорок модифікацій на місяць,
для подвоєння бюджету потрібно п'ятсот. Команда вже працює на дев'ятнадцять відсотків понад норму.
Вручну це ще чотири-шість дизайнерів.

**vo_04 (10 с).** Тому ми зробили SockLock Variants. Вставляєш переможця — отримуєш двадцять готових
варіантів тексту під таймінг відео.

**vo_05 (14 с).** Як цим користуватись. Перетягни файл зі скриптом або просто встав текст. Кожен рядок —
сегмент з таймінгом, голосом і текстом на екрані.

**vo_06 (8 с).** Вибери, скільки модифікацій потрібно, за замовчуванням двадцять, і натисни
«Згенерувати».

**vo_07 (4 с).** Пів хвилини — і готово.

**vo_08 (20 с).** У таблиці кожен варіант має назву для кабінету, позначку, що саме змінено, — хук, перша
фраза чи текст на екрані, — і кут: біль, цифра, гумор, демонстрація. Якщо варіант задовгий або обіцяє
зайве, побачиш червоний тег.

**vo_09 (14 с).** Натисни стрілку — і побачиш весь скрипт з новим текстом. Синім — що змінено. Жовтим —
сусідня фраза, яку інструмент підлаштував, щоб усе звучало зв'язно.

**vo_10 (22 с).** Щось не так? Відкрий чат з цим варіантом і напиши звичайними словами: коротше, смішніше,
без слова «магніт». Нова версія з'являється під оригіналом і проходить ті самі перевірки.

**vo_11 (10 с).** Скопіюй варіант одним кліком або вивантаж усе в CSV — назви вже готові для запуску в
рекламі.

**vo_12 (20 с).** Що це дає. Текст модифікації — десять хвилин замість півтори години. Модифікація —
година сорок замість трьох. Ті самі шість людей роблять чотириста тридцять модифікацій на місяць, плюс
шістдесят сім тисяч доларів валового прибутку щомісяця. Інструмент коштує до ста доларів на місяць.

**vo_13 (5 с).** Пілот — два тижні. Відкривай і встав свого переможця.

## Як зібрати відео

```bash
uv run uvicorn socklock_variants.web:create_app --factory --port 8077   # окремий термінал
uv run python demo/record.py      # demo/raw/: scene*.mp4, app.mp4, marks.json (~5 хв, генерації справжні)
# озвучку покласти в demo/vo/vo_01.mp3 … vo_13.mp3
uv run python demo/assemble.py    # demo/socklock-variants-demo.mp4
```

Без озвучки `assemble.py` збирає німу чернетку за плановими довжинами сцен.

## Монтаж (`assemble.py`)

- Нарізка за озвучкою: кожна сцена = довжина свого `vo_XX` + 0,3 с повітря.
- Сцена 7: очікування генерації прискорене без підпису — це демо, не замір швидкості.
- Підписи-кроки внизу в гайді («1 Перетягни скрипт…», «2 Вибери кількість…», …) малюються на сторінці під час запису, щоб відео працювало і без звуку.
- Теги (сц. 8) підсвічуються пульсуючою рамкою прямо на сторінці під час запису.
- Переходи — короткий fade 0,3 с, без «вау-ефектів».
- Гучність озвучки нормалізую до −16 LUFS.
